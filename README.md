# GPT 桌面伙伴 · GPT Companion 1.2.15

developed by WodeFafa

Windows 独立桌面伙伴，提供像素风与二次元风两套白发龙娘形象，自称 GPT。角色图集已经嵌入 EXE，不需要把图片文件放在程序旁边。

## 安装版

运行 `GC v1.2.15 Setup.exe`，选择安装位置后点击「一键安装」。可勾选桌面快捷方式，安装完成后可立即启动。默认仅为当前 Windows 用户安装，无需管理员权限；可从 Windows「设置 → 应用」卸载。覆盖安装和卸载均保留个人计划、日程、词库及登录记录；卸载只清理本安装目录的程序、快捷方式和指向本安装目录的自启项。安装前请先从旧桌宠右键菜单退出程序。

仍提供免安装压缩版，安装版和免安装版共用本机已有个人数据，安装包不包含任何个人记录。

## 开始使用

1. 更新时先在旧桌宠右键菜单选择「退出」（关闭伙伴中心只会收起到托盘）。把压缩包完整解压到固定文件夹，双击 `DragonCompanion.exe`；伙伴中心标题及左下版本为 v1.2.15。
2. 在「陪伴与换装」选择像素风或二次元风。
3. 在「任务与额度」点击刷新。电脑已登录 Codex 时会自动复用；没有登录则到「桌宠设置」点击「使用 ChatGPT 登录」，在浏览器完成官方授权。
4. 希望开机运行时，在「桌宠设置」勾选「开机自启（当前用户）」。以后登录 Windows 后会启动桌宠，自动复用仍有效的官方登录凭据，并刷新额度。
5. 想只保留 GPT 桌宠时，在「桌宠设置 → 原生桌宠」点击「关闭 Codex 原生宠物」。也可通过 GPT 的右键菜单使用此功能。
6. 玩 osu!mania 时，在「游戏中心」打开 osu!mania 的游戏设置，选择游戏 EXE，选择 4K／5K／6K／7K／8K，点击「重置键绑定」后按顺序录入键位。启动游戏后 GPT 会飞到选定的屏幕角落。

系统要求：Windows 10/11，.NET Framework 4.8。桌宠本身不需要 Node、Python、.NET SDK 或管理员权限。额度与登录功能另外需要已安装的 Codex CLI；本机环境已验证可用。在其他电脑上找不到 CLI 时，请在桌宠设置中选择 `codex.exe`。

## 单词卡片

进入「实用工具 → 单词卡片」，勾选高考3500、大学英语四级、六级、雅思或多个自定义词库，点击首页右上角统一的「开始单词卡片」后，正面显示单词，点击后以翻转动画展开解释、例句和变形。按空格或「下一张」切换，点击「掌握，不再显示」会保存掌握状态并跳过该词。

点击「浏览词库」可输入单词检索，用单词右上角的勾选框标记或解除掌握。解除后，该词会重新加入该词库的卡片。掌握状态按词库分别保存。

可以创建多个自定义词库，分别保存不同领域的词汇，并在词库卡片上修改名称。多个词库混合随机学习时，同一个单词只出一张卡片，学习进度与掌握记录分别计入包含该词的所选词库。各词库继续使用各自设置的每日目标。自定义词库支持添加和编辑单词。输入单词后停顿、按回车或离开输入框会自动补全解释、例句和变形。优先使用本地词典，未收录或缺少字段时复用已登录的 Codex 生成，需要联网及可用额度。生成内容可编辑后保存，换词或关闭窗口会取消旧请求。学习记录独立存放在用户数据目录的 vocabulary.json，并保留恢复副本。

在「每日目标」分别设置每天新学和复习的词数。看过答案后切换下一张，或直接标记掌握，计入当天进度。复习从此前学过且尚未掌握的词中选择，同一单词同一天只计一次。可用词不足时按实际数量计算目标。

勾选「加入制定计划和日程提醒」，设置结束日期、学习提醒与晚间询问时间，会创建对应的每日单词计划。达到当日目标后自动打勾；计划详情里的「开始学习」可直接进入卡片。

词库随程序离线提供。高考3500沿用源词表名称，包含拆分词条与短语，界面显示实际词数。少量词条的例句或词形原始数据缺失时，卡片会注明。数据来源、许可与可重建的词库源数据见随包的词库说明和 vocabulary-data-source.zip。
## 制定计划

在「实用工具 → 制定计划 → 新建计划」填写目标和结束日期，设置每天可投入时间、每日提醒及晚间询问时间。点击「由 Codex 生成并加入日程」，每日安排完成后会自动写入「日程提醒」。使用电脑上已登录的 Codex，生成和重排需联网且有可用额度。

每天在设定的晚间时间询问尚未确认的任务。选择「已完成」会在每日计划表及日程提醒中同步打勾；选择「未完成，重新安排」可补充原因，Codex 会按剩余期限重新制定后续安排。关闭询问窗口后仍可在「晚间复盘」或日程表回复；软件关闭时不弹窗，24 小时内重新运行会补发尚未送达的询问。

可提前勾选未来的任务，再选择「完成并调整相关任务」或「只完成，原定当天休息」。两种选项都保留原定日期和实际完成时间。选择调整时，同一计划里后续同主题的练习、复习按原顺序补位，关联提醒随日期更新。选择休息时，其余日期照旧，后续自动重排也会跳过该休息日。新计划使用具体主题标签，已有计划根据标题与备注中可匹配的主题处理。

点「修改期限与提醒」可提前或延后结束日期，保存后自动重排未完成内容；已完成和已反馈的历史保留。缩短期限会移除旧的未来任务。若期限内已没有可安排日期，可延长期限；生成失败后也可以点击「重新安排」重试。暂停计划会暂停该计划的每日提醒和晚间询问。

## 界面、窗口与启动

字体随窗口可用宽高自动缩放。拖动窗口时复用现有控件，采用缓冲绘制和连续缩放过渡，避免反复重建页面造成的闪烁，并保留输入光标与选中文字。不再提供独立字号设置；之前保存的固定字号也不再影响界面。在「桌宠设置 → 界面设置」可调整窗口宽高或恢复默认。窗口支持拖动边缘、最大化和「适应当前屏幕」，会记住上次大小及最大化状态；首次打开或分辨率改变后会收回屏幕可用区域。主页随宽度切换双列／单列，窄窗使用紧凑侧栏；内容较多时可滚动查看。调整窗口或切换页面不会丢掉尚未发送的输入；缩放过程中也会保留未完成的键位绑定。角色大小仍由原来的换装设置单独控制。

开机启动沿用当前用户的自启设置。程序先显示当前风格，其他动作和游戏素材按需加载，常用动作稍后预热；通知命令与再次启动不会先解码全部图片。已启用自启时，运行新版会更新已有自启项的程序路径，避免下次登录继续启动旧文件。请完整解压到固定文件夹后运行。

本机测得的程序内部首帧准备时间由约 2.99 秒降到约 0.3～0.6 秒；此值不包含 Windows 登录调度、CLR 加载和系统繁忙造成的等待，不等同于整机开机时间。EXE 现已嵌入 16～256 像素的多尺寸 GPT 图标，构建时校验图标资源及透明度。

像素风 CS2 的半尺寸显示改用平滑缩放，减少密集锯齿和动作闪烁；二次元 CS2、普通像素桌宠与 osu!mania 保持原来的渲染。右键「游戏模式」及「实用工具」末尾分别有「进入游戏中心」「进入实用工具」，具体开始、暂停和位置设置仍在各自界面。

## 常用操作

| 操作 | 结果 |
| --- | --- |
| 单击角色 | 摸摸头、随机回应 |
| 同时按住鼠标左右键拖动 | 从腰部揪起角色移动；松开任一键放下并记住位置 |
| 只按住左键或右键移动鼠标 | 不拖动角色 |
| 双击角色 | 打开伙伴中心 |
| 右键角色或托盘图标 | 换装、显隐、刷新额度、退出等 |
| 点击带任务关联的提醒气泡 | 尝试打开对应 Codex 会话 |
| 关闭伙伴中心窗口 | 收起到托盘，桌宠继续运行 |
| 再次打开 EXE | 唤起已运行的伙伴中心，不创建第二只 |

默认 128 px 小尺寸，支持 128、192、256、320 px 四种大小、置顶、提示音、免打扰及连续行走和扇翼飞行动画。行走采用固定身体与独立手脚，约每秒完成一轮左右腿交替，手臂与对侧腿配合。揪起使用完整独立图片与轻微摇摆，避免图集切割截断。揪起时身体横向、面朝下，腰部抬起，头和四肢自然下垂；放下时播放落地过渡。

首页「对话风格」可选傲娇、可爱、温柔、简洁，影响打招呼、摸摸头、道谢、休息及口令提示的语气，设置自动保存。它不会改变任务状态、额度数据或动作频率。待机不自动招手。日常会随机轮换看书翻页、喝茶和抱枕休息；看书使用八帧翻页，其余动作用完整底图生成连续局部运动，抱枕只眨眼，不会紧接着重复同一动作；动画使用固定人物底图，只更新局部手臂与道具，头部、身体基底和双脚不会随每帧漂移。书页按两种画风的真实书脊位置分别校准，在书本上缘翻动，不会抬到脸前。每翻三页保留原来的持书思考姿势约 6 秒，再继续翻页；看书安排得少一些，整段阅读可停留 22–32 秒。任务工作时敲键盘、等待回复时看问号卡、完成时举手欢呼，身后有连续运动的小花和彩带；日程到时查看便签，右手铃铛仅左右小幅轻晃；番茄钟结束改为抱枕休息。任务、拖动、行走和游戏模式可立即打断日常动作。开启闲时移动后，仍在每次移动之间停留 35–65 秒；步行单次目标距离增至 220–360 像素，飞行水平 260–420、垂直 120–200 像素，屏幕边缘自动限制，移动速度和休息频率不变。两种画风的动图在 verification/activity-preview.html 中。

上方回答气泡按文字长度调整宽高并自动换行，超长通知显示摘要，完整内容可到任务页查看。底部状态气泡按文字宽度收缩，平时隐藏，单击角色后显示约 4 秒，再用 1 秒淡出。桌面角色、气泡和右键菜单不显示开发者署名；伙伴中心等页面保留 developed by WodeFafa。互动输入框、风格和尺寸选择器、数值加减框、勾选框、卡片和菜单统一采用紫色圆角样式。选择器支持点击展开、键盘上下键切换；数值框支持直接输入、加减按钮和上下键。

互动输入框目前是**本地口令互动**：你好、在吗、谢谢、额度、番茄钟、日程（也兼容旧口令“倒计时”和“专注”）、休息、晚安。它不是独立的大模型聊天客户端，也不会因为摸摸头或输入口令而发送模型请求。

## osu!mania 游戏中心

支持 osu!(lazer) 与经典版。自动识别优先查找 `%LOCALAPPDATA%\osulazer\current\osu!.exe`，没有找到安装目录时再识别常见游戏进程。lazer 请选 `current` 文件夹中的 `osu!.exe`；选择窗口会自动定位已发现的安装目录。

游戏中心是支持鼠标滚轮的游戏列表，目前包含 osu!mania 与 Counter-Strike 2；游戏数量超出可见区域时可上下滚动。点击游戏卡片或「游戏设置」进入详情，也可返回游戏列表。在 osu!mania 详情中用「选择游戏程序…」定位本机 osu! 的 EXE。软件按这个完整路径识别正在运行的游戏；未选择时优先定位本机 lazer，找不到时再识别常见 osu! 进程名。仅支持 osu!mania 定轨显示，不解析谱面或成绩。4K、5K、6K、7K、8K 按钮只切换键数，屏幕、实体键盘和下方键帽同步更新。点击独立的「重置键绑定」后，所有键位框立即清空，随后按时间顺序从左向右逐个显示按键名称，录满后自动保存；五个模式各自保存。键位框只显示名称，不带编号，点击不会开始绑定；已移除取消绑定选项。长按产生的重复输入会被忽略，重复检查只针对本轮已经录入的键。录入区域临时禁用输入法，并将中文输入法的 ProcessKey 消息恢复成实际按键；内部输入法键码不会被保存，聊天框仍支持中文。游戏打开后，GPT 暂停散步并飞往左下角或右下角；左下角朝右，右下角朝左。可随时在游戏中心切换角落。点击「设置固定位置」后，即使游戏尚未运行也会显示游戏场景预览；在紫色虚线框内任意位置同时按住鼠标左右键拖动，松开后保存整个游戏场景的位置，下次进入游戏会复用。「恢复默认位置」清除固定定位并返回所选角落。定位时鼠标变为移动指针，整块框内区域都可以抓取，临时置顶并隐藏旧提示气泡；先按下一个鼠标键时即保留鼠标捕获，便于接着按下另一个键。定位过程中保持完整场景，避免放下时跳位；恢复默认或切换左右角落也可结束定位。定位入口保留在伙伴中心的对应游戏设置页。

游戏姿势是侧背坐着打游戏。角色身下使用浅紫色软方枕，带细包边、轻微褶皱和接触阴影，像素风／二次元风及左右朝向均保持坐垫贴合膝腿，下方按键与坐垫分开留白。GPT 面前的电脑屏幕采用与角色一致的侧面透视，放在有桌腿支撑的桌面上；角色双手落在桌面实体键盘上。桌面已缩小、电脑移近；屏幕和实体键盘沿桌面横轴摆放，屏幕正面朝向 GPT，支架底座与屏幕中心对齐。电脑进一步移到桌面中间并靠近角色；游戏场景不再显示顶部的游戏名称及键数文字。二次元坐姿单独下移，让双手与键盘对齐；像素风人物位置保持原样。两种朝向均保持屏幕和键帽从左到右对应，角色向桌面中央靠近并稍微下移；桌腿按桌面透视延伸，靠近 GPT 的一侧不再偏短。实体键盘只在绑定了 Space 时显示空格键。像素风采用用户选定的第一张跪姿修正版。屏幕包含对应数量的竖轨；普通按键以圆角正方形单独显示在 GPT 下方。4K 为 2＋2，6K 为 3＋3，8K 为 4＋4，中间留空；5K 默认使用 2＋2 与第二排 Space。Space 显示英文名称，使用加长键帽，独占居中的第二排。按下的轨道和键位同步发光，GPT 的手部会小幅上下敲击，头部与身体保持固定；左右两组按键分别驱动两只手。按键只在指定游戏位于前台时读取，不记录按键历史，不向游戏发送输入。关闭 osu! 后，GPT 自动恢复正常工作状态并回到先前位置；从右键选定 osu!mania 时同样如此。电脑屏幕和下方键位区域对鼠标点击透明，尽量避免遮挡游戏操作；游戏检测约每 2 秒更新一次。右键悬停「游戏模式」只展开游戏名称列表；位置设置留在对应游戏页面，启用自动检测／暂停游戏模式在游戏中心列表右上角。模式选择自动保存；选定游戏时仍仅在游戏位于前台时响应绑定按键。右键菜单已移除「摸摸头」，可继续单击 GPT 或在首页使用。游戏中心为后续游戏保留独立配置入口，目前提供 osu!mania 与 Counter-Strike 2。

## Counter-Strike 2 模式

在「游戏中心 → Counter-Strike 2」启用自动检测。本机可自动定位 Steam 游戏目录，也可用文件选择器定位 `game/bin/win64/cs2.exe`；没有定位到安装目录时识别 `cs2` 进程。右键「游戏模式」也能选择 CS2；自动检测／暂停开关在游戏中心右上角。旧设置选过 osu!mania 时，不会阻止其他已启用游戏自动进入；前台游戏优先。

GPT 使用正面大头 Q 版形象，两套风格都有独立透明底图。CS2 场景整体为初版约一半大小，普通桌宠与 osu!mania 尺寸保持不变。画面左下是 GPT 右手和鼠标，右下是左手与半幅实体键盘；键盘和鼠标保持原来的左右位置，键盘采用近宽远窄的透视，Space 靠近 GPT，功能键一排在较远处。鼠标放在手掌下方：手指一侧为滚轮和左右键，手心一侧为白色后壳；鼠标与手共用移动及点击下压位移，不提供方向切换选项。WASD 为紫色半透明键帽，其他键为白色。按键时左上角气泡显示最近按下且仍按住的键，全部松开后隐藏；按键发光、左手前臂和手腕连续移动并下压。右手随鼠标位移和点击运动，头部由原始鼠标 X 轴位移驱动。角色使用二维贴图网格动画，呈现 Q 版模型风格，不是可自由旋转的三维模型。

CS2 位于前台时才处理即时键鼠反馈，切出游戏清空状态；不保存按键内容。使用 Windows Raw Input，在游戏锁定光标时仍能读取相对鼠标位移，不注入游戏或代替用户输入。关闭 CS2 后恢复普通 GPT 和原来的位置。

左下角／右下角、自定义固定位置与恢复默认位置均在 CS2 页面设置；同时按住左右键拖动紫框中的任意位置，松开保存。两个角落只移动场景，不颠倒键盘和鼠标。各游戏的位置互不覆盖。

「桌宠设置 → 桌宠位置」及右键「桌宠位置」新增自定义初始位置：双键拖动并松开后保存，以后启动优先使用此位置。平时散步和普通拖动不覆盖初始位置；点击恢复默认即可取消。

制作规范与素材位置见 [CS2_ASSET_PROMPTS.md](CS2_ASSET_PROMPTS.md)。`verification/cs2-anime-demo.gif` 和 `cs2-pixel-demo.gif` 是应用渲染器输出的动作预览，不是实际对局录屏。实机 CS2 对局反馈尚待验收。

## 实用工具

左侧「实用工具」是与游戏中心一致的可滚动列表，目前包含「番茄钟」和「日程提醒」。首页提供分类入口；右键「实用工具」列出番茄钟、日程提醒，底部提供「进入实用工具」；开始、暂停、继续、取消等操作位于工具窗口。后续新增工具和游戏也保留一层名称列表与中心入口。

### 番茄钟

原倒计时已更名为「番茄钟」。从实用工具或右键子菜单打开，可选 5、15、25、45、60 分钟，也能输入自定义分钟和秒数；支持暂停、继续、取消，到时提醒。点击角色可查看底部状态气泡中的剩余时间。番茄钟属于本次运行状态，退出软件会结束当前计时。

### 日程提醒

进入「实用工具 → 日程提醒」，统一使用「添加日程」按钮创建日程。弹窗填写日期、时间、事件、备注和重复方式；支持单次、每天、每周、每月、每年。每周可勾选多个星期。列表中可编辑、启用、关闭或删除日程，并查看下次提醒时间。

日程保存在用户数据目录的 `schedules.json`，软件重启后保留，按本机日历时间提醒。每月 31 日遇到短月时使用当月最后一天，之后仍按原来的 31 日计算；每年 2 月 29 日在普通年份使用 2 月 28 日。单次提醒触发后标为结束，不会重复弹出。多条日程同时到时会合并显示，并保留完整事件和备注到提醒历史。

软件运行时大约每 2 秒检查一次日程；关闭期间不会弹窗，重新启动或唤醒后补发 24 小时内最近一次到期提醒，不逐条补发长时间离线期间的所有重复事件。全局免打扰同样作用于日程提醒。

### 图标与后续扩展

番茄钟、日程提醒分别使用独立的紫白线条圆角方形图标。以后新增工具时，必须增加对应图标和预览，沿用相同的线宽、圆角和留白。

游戏图标以该游戏的原图标为基础，读取较高分辨率后转为紫色轮廓、白色背景。圆形原图不额外套方框；方形原图保持原尺寸，直接裁掉四角并保留最外层紫色圆角边框；CS2 内部只保留人物紫线和白底，不增加第二层方框。轮廓使用平滑曲线和抗锯齿绘制，忽略背景色块分界。选定游戏程序后优先使用该程序原图；osu!mania 和 CS2 另内置已提取的原始图标，避免路径暂不可用时丢失标志。

详细扩展规则见 [DESIGN_GUIDE.md](DESIGN_GUIDE.md)。

## 登录、凭据与额度

登录使用 Codex 官方 `account/login/start` 浏览器授权流程；账号密码只在官方页面输入。**软件不记录明文密码**，也不复制 Codex 的访问令牌。登录凭据由官方 Codex 管理，下次启动继续复用，授权失效后需要重新登录。

额度通过官方 `account/rateLimits/read` 接口读取，显示的是 **Codex 账号对应额度池**，不是通用的 ChatGPT 剩余消息次数，也不是 API 账户余额。短周期、长周期、额度池选项、重置时间均按服务返回数据呈现。没有数据时显示「—」；缓存过期或查询失败会明确标注，不会假装仍然是实时值。

默认 5 分钟刷新，可调为 1–60 分钟，也可以手动刷新。查询不会主动消耗额度重置次数。首次启动联网读取额度，但本地互动与角色显示可离线使用。

## 任务提醒的覆盖范围

软件每 2 秒增量读取当前用户 `CODEX_HOME/sessions`（未设置则使用用户目录的 `.codex/sessions`）中的本地事件，识别开始、完成、中断、失败、请求用户输入及已记录的审批请求。

- 只提醒软件启动以后新增的事件，避免把历史任务当成刚完成。
- 最近记录最多保留 100 条；免打扰时继续记录，但不弹气泡、不响铃。
- 只监听主聊天会话：后台审核和其他子会话结束不会触发完成提醒；主聊天整轮结束才提示完成，同一轮重复结束事件只提醒一次。出错与中断单独提示。
- 对于写入主聊天本地会话的请求，提示你回到 Codex 处理；软件不会替你批准操作或提交回复。
- 云端任务、远程主机，以及未写入本地会话的审批请求不保证能自动发现。Codex 日志格式变化可能影响识别。
- 运行中的任务若在桌宠启动前已开始，其「工作中」状态可能要等下一条相关事件才更新。

其他程序也可通过本地命令通知 GPT。先启动桌宠，然后执行：

```powershell
.\DragonCompanion.exe --notify complete "文件处理完成"
.\DragonCompanion.exe --notify waiting "请查看待确认事项"
.\DragonCompanion.exe --notify error "任务失败，请查看日志"
```

可用状态：`working`、`complete`、`waiting`、`error`、`interrupted`。可在最后附加 `--thread "会话 UUID"` 来关联 Codex 会话。

## 切换 Codex 原生虚拟宠物

「原生桌宠」页面及右键菜单提供关闭与显示按钮。软件调用 Codex 主界面左下角头像菜单中的「显示虚拟宠物／隐藏虚拟宠物」，并读回菜单或 Codex 保存的开关状态后报告结果。它不会结束 Codex/ChatGPT 进程，也不会修改应用文件或直接写入 Codex 的全局设置文件。

操作前会确认官方安装路径、Codex 主窗口和头像菜单中的唯一宠物命令。找不到或有歧义时会停止并提示。Codex 客户端改版、界面语言或辅助功能标签变化可能影响识别。本机已实际完成显示→关闭循环，并验证 Codex 最小化时仍能切换且保持最小化。

「启动时关闭原生宠物」默认关闭。启用后会在 GPT 桌宠启动约 6 秒后尝试一次；如果 Codex 更晚启动，可再点击按钮。当前状态会随 Codex 保存的开关状态刷新。关闭或重启 GPT 桌宠不会自行重新显示 Codex 原生宠物。

## 文件、更新与卸载

用户数据位于 `%LOCALAPPDATA%\DragonCompanion`：

- `settings.json`：风格、位置及偏好。
- `quota.json`：最近额度及更新时间，不含令牌。
- `history.json`：最近的简短提醒记录。
- `diagnostics.log`：发生错误时的诊断信息。
- `inbox`：本地程序通知队列。

开机自启使用当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中的 `DragonCompanion` 项。程序不会申请管理员权限。移动 EXE 后，应关闭再开启一次自启选项以更新路径。

更新前通过托盘退出 GPT 桌宠，再替换 EXE。卸载时先取消开机自启并退出，然后删除程序文件；如果不再保留偏好，可手动删除上述用户数据文件夹。卸载不会退出官方 Codex 账号。
